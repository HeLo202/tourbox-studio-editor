如何使用和刷写？
  1. 选择控件，设置按键与修饰键。预设自动保存在当前浏览器。
  2. 不同网站的预设不会自动同步。如需迁移，请在旧网站导出 JSON，再在此处导入。
  3. “临时应用”需要桌面版 Chrome 或 Edge，并需要设备运行此项目的固件；断电后失效。
  4. “下载可刷入固件”会把当前预设写入 UF2 应用镜像。仅在确认实际模块、引导程序和 PCB 接线后，复制到对应 UF2 磁盘。
  5. 原版控件的动作、组合与 TourMenu 仍在 TourBox Console 中配置。

第三编码器需要两根已规划的飞线；矩阵复用 NFC 引脚，若设备仍处于 NFC 模式将阻止扫描。硬件、复合 USB 和 Console 共存仍需实板验证。
